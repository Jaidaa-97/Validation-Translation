LHW translation validator

Upload your CONTENT sheet and compare Excel copy to every live LHW language site (Playwright).

Leave blank to use the default hotel URL. The run automatically checks all configured language hosts (www, de, it, fr, jp, es).

How column A labels are matched on the site (click to expand)

The tool reads column A (section name) and compares your Excel text (columns B–G) to the matching block on each live LHW language page.

  • Dining & restaurants — Labels mentioning restaurant, dining, etc. open …/services-amenities/dining and compare restaurant copy.
  • Spa & wellness — Labels like Spa, Wellness, or Spa Description open …/services-amenities/spa. “Spa Name” / “Spa Title” compare the title only; “Spa Description” uses the body text.
  • Hours of Operation — Compares div.hours on the dining page. Use Restaurant #1 Hours… or the outlet name in column A when a hotel has several restaurants.
  • Property Highlight — e.g. “Property Highlight #2 Description” matches the three overview highlight tiles.
  • Property search — Searches LHW from your /hotel/… URL and reads p.hotel-desc on the results page.
  • Column H (special note) — Text in column H compares that row against the property-overview block (not used for highlights or message-banner rows).
  • Overview notices — Renovation Notice, Special notice, Message banner, or Hotel message match the corresponding overview notice on the hotel page.
Troubleshooting (optional)

If the site blocks the automated browser, restart the server in PowerShell with visible Chrome: 

$env:HEADLESS="false"; $env:PW_CHANNEL="chrome"; npm start
