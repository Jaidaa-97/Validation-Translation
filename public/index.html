How column A labels are matched on the site (click to expand)

The tool reads column A (section name) and compares your Excel text (columns B–G) to the matching block on the selected live LHW language page.

  • Dining & restaurants — Labels mentioning restaurant, dining, etc. open …/services-amenities/dining. Each outlet is matched by name and Excel copy (not by its position on the page), including hours and descriptions.
  • Spa & wellness — Labels like Spa, Wellness, or Spa Description open …/services-amenities/spa. “Spa Name” / “Spa Title” compare the title only; “Spa Description” uses the body text. Spa Hours (or similar) compares the schedule paragraph (e.g. Weekdays, Fitness Center, Massage times in a <p>).
  • Golf — Labels mentioning golf open …/services-amenities/golf. Each course is matched by name (e.g. h3.golf-course-title). Use “Golf #1 Name”, “Golf #1 Description”, or “Golf #1 Hours” for multi-course hotels. “Golf Lessons” / “Golf Lessons Note” (full tile div), “Dress Code” (tile div), and “Handicap Men” / “Handicap Women” (p lines) read pinned selectors under #hotel-amenities. Handicap rows pass when expected text appears inside the scraped line. Golf Hours of Operation use #hotel-amenities … section.course-hours div.hours on the overview; per-course hours use the golf subpage.
  • Hours of Operation (dining) — Compares div.hours on the dining page. Use Restaurant #1 Hours… or the outlet name in column A when a hotel has several restaurants. Each outlet is matched by name, description, or hours text — not by its position on the live page.
  • Property Highlight — e.g. “Property Highlight #2 Description” matches the three overview highlight tiles.
  • Property search — Searches LHW from your /hotel/… URL and reads p.hotel-desc on the results page.
  • Column H (special note) — Text in column H compares that row against the property-overview block (not used for highlights or message-banner rows).
  • Overview notices — Renovation Notice, Special Notice, Message banner, or Hotel message match the corresponding overview notice on the hotel page. Hotels with several blue info strips (e.g. Shilla Seoul) are read in order; use Special Notice #1, #2, … in column A, or rely on sheet order when labels have no number.
Troubleshooting (optional)

If the site blocks the automated browser, restart the server in PowerShell with visible Chrome: 

$env:HEADLESS="false"; $env:PW_CHANNEL="chrome"; npm start
